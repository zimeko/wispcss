Color System

WispCSS color system built on OKLCH color space. Adjust controls to preview real-time color changes.

Notes

  • Color system uses OKLCH color space for perceptual uniformity.
  • --color-c-factor controls saturation; --light-threshold-* controls contrast text brightness.
  • Each theme color has 13 derived variants (hover, active, contrast, body, surface, fg, bg, bg-hover, bg-active, bd, bd-hover, bd-active).
  • Typically you only need to modify --color-primary-base, --color-secondary-base and --color-tertiary-base to change the theme style with just three colors.
  • Adjust color base values and light parameters below to see real-time updates on cards and buttons.
