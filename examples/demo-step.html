Step Component

Step / progress indicator with nodes, tracks, labels, and description. Uses data-role attributes (node, track, label, description, header) and data-selected="true" for the current step.

Notes

  • Base: .step , .step-v (horizontal) or .step-v (vertical). data-selected="true" marks current step.
  • Structure per step: [data-role="header"] (time), [data-role="track"] (line + [data-role="node"] dot), [data-role="body"] with label + description.
  • Variants: step-solid (filled dot), step-plain (text-only, no border/background).
  • Layout: step-between (justified ends), step-trim (hide leading/trailing track).
  • States: step-reverse (completed = gray, upcoming = colored), step-pending (waiting state).

Custom colors

Multiple color formats are supported:

  • 1. Theme semantic colors, e.g. *-error, *-error-hover
  • 2. Tailwind built-in colors, e.g. *-indigo-500
  • 3. Raw color values, e.g. *-[#ff0000]
  • 4. CSS named colors, e.g. *-[red], *-[green]
