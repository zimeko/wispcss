Divider Component

Horizontal and vertical divider component with label support.

Notes

  • Base class: .divider. Use .divider-h for explicit horizontal (same as .divider).
  • Vertical: use .divider-v. With label, width expands to 1.5em.
  • Label positions: default (center), .divider-start (left), .divider-end (right).
  • Line styles: .divider-dotted, .divider-dashed, .divider-slash.
  • Sizes: divider-1 ~ divider-10 (1px ~ 10px thickness). Custom via --divider-size.
  • Colors: use divider-* dynamic utilities (e.g. divider-primary, divider-error).

Custom colors

Multiple color formats are supported:

  • 1. Theme semantic colors, e.g. *-error, *-error-hover
  • 2. Tailwind built-in colors, e.g. *-indigo-500
  • 3. Raw color values, e.g. *-[#ff0000]
  • 4. CSS named colors, e.g. *-[red], *-[green]
