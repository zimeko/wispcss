Empty Component

Empty state placeholder with text and optional SVG illustration. Supports data-empty for custom messages and --i18n-no-data for locale defaults.

Notes

  • Base class: .empty. Displays centered caption text via ::before pseudo-element.
  • Custom text via data-empty="Your message" attribute. Falls back to --i18n-no-data CSS variable (default "No Data").
  • Add .empty-illustrated for an SVG illustration above the text.
  • Children (e.g. buttons, links) are automatically placed below the text via flex column layout.
  • Custom colors are supported — .empty text and SVG illustration color inherit from text-* utilities (e.g. text-gray-300).
