Tree Component

Hierarchical tree built on ul/li with states, shapes, densities, indent modes, node styles, grouping, checkboxes, notes, toggle expansion, and dynamic colors.

Notes

  • Structure must be ul > li. Each row is div[data-role="node"] containing div[data-role="content"] > span[data-role="label"] and optionally span[data-role="arrow"], .check + input, div[data-role="note"], span[data-role="spacer"], div[data-role="custom"].
  • Child levels are wrapped by div[data-role="children"] > ul placed right after the node row. The top-level ul does not need a data-role="children" wrapper.
  • Trees cannot be nested. Do not use ul/li inside non-list nodes.
  • Every branch node requires a span[data-role="arrow"] to keep indentation consistent; the arrow content is hidden automatically for leaf nodes.
  • Child levels are collapsed by default. Use .tree-expanded (one branch), .tree-expanded-n (up to level n), or .tree-expanded-all (all) to expand, or a <input data-role="toggle" type="checkbox"> for interactive CSS-only toggling.
  • Grouping: use div[data-role="group"] as a non-selectable section label; its indentation aligns with its child nodes.
  • .tree-selected colors the whole row, .tree-active colors only the label, and .tree-disabled disables a row or the root.
  • Edit mode replaces the label text with an <input> inside span[data-role="label"].
