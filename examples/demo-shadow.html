Shadow Utilities

WispCSS supplements Tailwind's built-in shadows with additional CSS variables for common UI layers. Tailwind shadow-* classes work directly.

Notes

  • WispCSS adds shadow variables beyond Tailwind's defaults: --shadow-base, --shadow-border, --shadow-border-inner, --shadow-bubble, --shadow-card, --shadow-desk.
  • Tailwind built-in shadow classes: shadow-sm, shadow, shadow-md, shadow-lg, shadow-xl, shadow-2xl, shadow-inner, shadow-none.
  • Custom shadow color: shadow-lg shadow-blue-500/50 (Tailwind v4).
  • Arbitrary shadow: shadow-[0_10px_40px_rgba(0,0,0,0.3)].
