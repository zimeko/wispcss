Icon Component

Vector icons implemented with CSS mask-image. Color via text-* or icon-* utilities. Supports multiple icon families, sizes, and custom colors.

Notes

  • Base class: .icon. Shape class: icon-* (e.g. icon-check).
  • Icon color follows currentColor by default. Use text-* utilities or inline style="color:..." to set color.
  • Sizes via icon-* dynamic utilities (e.g. icon-6, icon-10, icon-20, icon-[28px]).
  • More icons will be added in future releases.
