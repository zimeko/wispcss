Breadcrumb Component

Breadcrumb navigation with variants, custom separators, and semantic data attributes.

Notes

  • Use class .breadcrumb on a <nav> or <div> container.
  • Labels use data-role="label", separators use data-role="hyphen", and optional prefix uses data-role="header".
  • Mark the current page with data-selected="true".
