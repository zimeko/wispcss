Details / Summary Component

Native HTML <details> / <summary> elements styled by preset.css. No JavaScript required for expand/collapse interaction.

Notes

  • Use <details> as the container and <summary> as the clickable header.
  • Add open attribute to keep the panel expanded by default.
  • Add disabled attribute to disable interaction (optional browser support).
  • Nesting is supported — place <details> inside another <details> for tree-like navigation.
