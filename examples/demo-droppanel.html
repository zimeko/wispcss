Droppanel Component

Pure CSS dropdown panel with fully customizable content. Supports hover/click toggle, inline mode, multiple positions, and custom panel content.

Notes

  • Base class: .droppanel. Structure: droppanel > label/span/host > [data-role="panel"].
  • Panel content is fully customizable — use <div data-role="panel"> as container.
  • Hover expands by default. Use label > input[type=checkbox] for click toggle.
  • Use .droppanel-inline for inline expansion (content pushes siblings).
  • Use data-role="host" on trigger for arrow indicator. Use data-expanded="true" for persistent open.
  • Positions: .droppanel-bottom-*, .droppanel-top-*, .droppanel-end-*, .droppanel-start-*
  • Combine with .bubble class on the panel element for bubble-style appearance.
