Actions Component

Action bar for footer areas (card / dialog / modal) with start, center and end aligned groups.

Notes

  • Use .actions as the container; child groups use .actions-start, .actions-center and .actions-end.
  • Each group lays its content in a row with a consistent gap, so text, buttons, checkboxes and other inline content can be mixed freely.
  • An empty .actions bar is hidden automatically.
