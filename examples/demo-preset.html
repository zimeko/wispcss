Preset Styles

HTML base element resets and theme tokens from preset.css (@layer base). No extra utility classes needed — these styles apply to native elements automatically.

Notes

  • All styles live in @layer base and require no extra classes to activate.
  • Theme tokens define spacing (4px base), border-radius, shadows, transitions, direction factors (LTR/RTL), and light/dark scheme thresholds.
  • Custom scrollbar (8px, desktop only), focus-visible outline, and placeholder styling are globally applied.
  • Forms, inputs, selects, textareas get unified height (32px), border, hover/focus states, and disabled opacity.
