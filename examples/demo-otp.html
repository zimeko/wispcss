OTP Component

One-Time Password / PIN input container. Wrap multiple input elements inside .otp to create auto-sized square inputs with centered monospace text.

Notes

  • .otp uses inline-flex layout — inputs sit in a single row.
  • Each input becomes a square whose size is driven by the input-* class (e.g. input-10 → 40×40px).
  • OTP inherits input variant utilities: input-subtle, input-ghost, input-underline, input-outline, input-rounded.
  • For production use, pair with a JS script for auto-focus, arrow-key navigation, and Backspace-to-clear.

Custom colors

Multiple color formats are supported:

  • 1. Theme semantic colors, e.g. *-error, *-error-hover
  • 2. Tailwind built-in colors, e.g. *-indigo-500
  • 3. Raw color values, e.g. *-[#ff0000]
  • 4. CSS named colors, e.g. *-[red], *-[green]
