Callout Component

Callout container for alerts and tips. Uses fixed font-size for visual prominence.

Notes

  • Prefer combined utilities like callout-solid-primary over separate callout-solid callout-primary — smaller CSS output.
  • Use data-role="title" and data-role="icon" for structured callout content with larger title/icon sizing.
  • Default font-size is 14px (0.875rem) — no responsive scaling to maintain visual prominence.

Custom colors

Multiple color formats are supported:

  • 1. Theme semantic colors, e.g. *-error, *-error-hover
  • 2. Tailwind built-in colors, e.g. *-indigo-500
  • 3. Raw color values, e.g. *-[#ff0000]
  • 4. CSS named colors, e.g. *-[red], *-[green]
