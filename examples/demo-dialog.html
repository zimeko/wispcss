Dialog Component

Native <dialog> component. Supports :target (anchor), show() and showModal() open methods. Structure: dialog > [data-role="header"] > [data-role="title"] + [data-role="tools"] + [data-role="body"] + [data-role="footer"].

Notes

  • Use native <dialog> element — accessible and semantic.
  • Three open methods: :target (anchor link), dialog.show() (no backdrop), dialog.showModal() (with backdrop).
  • Required slots: data-role="header" / data-role="title", data-role="tools", data-role="body", data-role="footer".
  • Anchor links use <a href="#dialogId"> to open and <a href="##"> to close.

Class dialog component

Pure CSS dialog built with .dialog + .dialog-wrapper structure. Toggled by adding / removing the .dialog-open class.

Notes

  • Base: .dialog (overlay) → .dialog-wrapper (card surface).
  • .dialog-open and .dialog-close are mutually exclusive: add .dialog-open to show, remove it and add .dialog-close to hide.
  • .dialog-backdrop is optional — without it the dialog clicks through.

Available child nodes of .dialog:

  • .dialog-wrapper — content wrapper (card surface, required)
  • .dialog-backdrop — backdrop layer (optional; without it the dialog clicks through)
  • .dialog-tools — tools bar, absolutely positioned top-end (optional)
  • .dialog-header — header container (optional; auto-hidden when empty)
    • .dialog-title — title, child of header (optional, ellipsis truncation)
  • .dialog-body — scrollable main area (required)
    • .dialog-content — content container, child of body (inherits border radius)
  • .dialog-footer — bottom action area (optional)
    • .actions — action bar with start / center / end groups
    • .btns.btns-flush — flush edge-to-edge button group
  • .dialog-note — note text area at the bottom (optional)

Width

  • dialog-* — any arbitrary width.
  • dialog-scale-* — proportional sizes based on --default-width-input; dialog-scale equals the default width of <input type="text">.
  • dialog-full — full width (keeping safe side gaps).
  • Without any width utility, the dialog width depends on its content.
dialog-100

Width = 100 spacing units (100 * 4px).

Width = --default-width-input.

Full horizontal width minus side gaps.

Special size

dialog-fullscreen is a special size: absolutely centered and fills the whole screen (keeping safe gaps on all sides). It is mutually exclusive with the position and width utilities.

fullscreen

Fullscreen-centered dialog, body flexes to fill and scrolls.

Custom open/close animations

Apply both enter and exit animation utilities to .dialog-wrapper via Tailwind variants. The enter animation is scoped to .dialog-open, while the exit animation is scoped to .dialog-close — since the two classes are mutually exclusive, the correct animation plays automatically.

[:where(.dialog.dialog-open)_&]:animate-*-in — enter · [:where(.dialog.dialog-close)_&]:animate-*-out — exit

See demo-animation.html for more available animations.
