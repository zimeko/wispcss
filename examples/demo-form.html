Form Controls

Native form control elements styled with WispCSS input utilities and defaults from preset.css.

Notes

  • All native input types (text, password, email, etc.) accept the same input-* utility classes.
  • <button>, <input type="submit/reset/button"> get basic btn styles by default from preset.css.
  • <select>, <textarea>, <progress>, <meter> are styled natively via CSS.
