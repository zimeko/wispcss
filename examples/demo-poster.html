Poster Component

Cover image container with aspect ratio, overlays, and hover effects. Requires a width, height, or aspect-ratio to render.

Notes

  • Base class: .poster. Default aspect ratio is 4/3.
  • Place <img> or <picture> inside. Missing or empty src shows "No image available".
  • Use data-content for custom overlay text on ::before, and data-content-hover for hover-only text.
  • Images use object-fit: cover by default. Empty poster shows a solid background.
