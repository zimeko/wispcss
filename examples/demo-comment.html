Comment Component

Comment list with nested threads, avatars, badges, media content (images/video/audio), quotes, polls, and link cards.

Notes

  • Use .comments > .comment structure for comment lists.
  • Recursive nesting: .comment > .comment-end > .comments > .comment for threaded replies.
  • Left slot (.comment-start) usually contains avatar; right slot (.comment-end) contains header, body, footer.
  • Use data-role="start" and data-role="end" in header/footer for layout split.
