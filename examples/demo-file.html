File Component

input[type=file] styling. Same input utility classes apply — supports variants, theme colors, sizes, radius, and width.

Notes

  • input[type=file] uses the same utility classes as input[type=text] — all variants, colors, sizes, radius, and width utilities work identically.
  • Prefer combined utilities like input-subtle-primary over separate input-subtle input-primary — smaller CSS output.
  • Disabled state is built-in: just add disabled attribute.

Custom colors

Multiple color formats are supported:

  • 1. Theme semantic colors, e.g. *-error, *-error-hover
  • 2. Tailwind built-in colors, e.g. *-indigo-500
  • 3. Raw color values, e.g. *-[#ff0000]
  • 4. CSS named colors, e.g. *-[red], *-[green]
