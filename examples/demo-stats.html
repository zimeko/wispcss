Stats Component

Numeric statistics display with label, prefix, suffix, and description text. Uses data-role attributes to structure the display.

Notes

  • Base: .stats (vertical) or .stats-h (horizontal). They are mutually exclusive utilities.
  • Structure: [data-role="main"] wraps the core value, [data-role="label"] for the number, [data-role="prefix"] / [data-role="suffix"] for units, [data-role="tips"] for description.
  • .stats-between adds space-between layout — works with both stats and stats-h.
  • Sizes: stats-4 ~ stats-15 control the label font size.
