Blob Component

Organic blob shapes with morphing animation. Combine blob-{shape} with size (w-* h-*), color (bg-*), and animation (animate-blob-morph) utilities.

Notes

  • Use blob-{shape} for a static organic shape.
  • Add animate-blob-morph (or variants animate-blob-morph1 ~ animate-blob-morph4) for continuous morphing.
  • Append -{ms} for custom duration, e.g. animate-blob-morph3000.
  • Shapes are clip-path-free — simply irregular border-radius values, fully compatible with overflow:hidden for images.

Dynamic duration

Multiple time formats are supported:

  • 1. Integer value, e.g. *-3000 (3000ms)
  • 2. Bracketed integer, e.g. *-[3000] (3000ms)
  • 3. Bracketed time string, e.g. *-[4s], *-[2000ms]
2s
animate-blob-morph-2000
3s
animate-blob-morph1-3000
5s

6s

Color variants

Multiple color formats are supported:

  • 1. Theme semantic colors, e.g. *-error, *-error-hover
  • 2. Tailwind built-in colors, e.g. *-indigo-500
  • 3. Raw color values, e.g. *-[#ff0000]
  • 4. CSS named colors, e.g. *-[red], *-[green]
