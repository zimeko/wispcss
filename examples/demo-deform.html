Deform Component

Deform icons built with CSS pseudo-elements. Supports plus, minus, close, menu, check, search, spinner, chevron, arrow and more. Color via text-* classes.

Notes

  • Base class: .deform. Shape class: .deform-* (e.g. .deform-plus).
  • Some shapes require a child element: menu*, arrow*, more-h/v, chevron*, info, warning, spinner.
  • Use .deform-flip to mirror chevron and arrow shapes horizontally.
  • Sizes: deform-2xs ~ deform-5xl.
  • Color: apply text-* utility classes (e.g. text-primary, text-error).
