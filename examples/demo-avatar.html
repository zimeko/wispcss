Avatar Component

Flexible avatar component with text/placeholder fallbacks, SVG masking, themes, and dynamic sizing.

Notes

  • Use <span class="avatar">A for text initials; add <img> child for images.
  • Empty or missing img[src=""] is hidden and the container shows fallback text "Null".
  • For background-image avatars, set style="background-image: url(...)" directly on .avatar.
  • RTL is auto-supported; avatar-bubble-start / avatar-bubble-end flip their tail direction.

Custom colors

Multiple color formats are supported:

  • 1. Theme semantic colors, e.g. *-error, *-error-hover
  • 2. Tailwind built-in colors, e.g. *-indigo-500
  • 3. Raw color values, e.g. *-[#ff0000]
  • 4. CSS named colors, e.g. *-[red], *-[green]
