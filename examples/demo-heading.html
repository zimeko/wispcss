Heading Component

Typography line-height demo for <h1> ~ <h6> across multiple languages. Line-height is optimized per script via lang attribute.

Notes

  • Heading line-height is automatically optimized based on the lang attribute.
  • CJK (Chinese/Japanese/Korean) scripts use tighter line-height by default.
  • Arabic and Latin scripts use standard line-height for readability.
