Dropmenu Component

Pure CSS dropdown menu built with ul + li + hover structure. Supports multi-level nesting, click toggle (checkbox), inline/list modes, multiple positions, submenu directions, ghost variant, and RTL.

Notes

  • Base class: .dropmenu. Structure: dropmenu > label/span/host > ul > li > ul (submenu).
  • Hover expands by default. Use label > input[type=checkbox] for click toggle.
  • Modes: .dropmenu-inline (inline expansion), .dropmenu-list (always expanded).
  • Visual: .dropmenu-ghost for ghost button style. Use data-role="divider" on li for separators.
  • Use data-role="host" on trigger for arrow indicator. Use data-expanded="true", data-selected="true", data-disabled="true" on li > div for states.
  • Multi-level nesting: li > ul > li > ul .... Submenus auto-position to the right (default growth).
