Position Component

Fixed / absolute centering, corner anchoring, and sticky offsets using logical properties.

Notes

  • Corner anchors default to 0 offsets; combine with Tailwind spacing (e.g. top-4) to adjust.
  • Absolute positioning requires position: relative on the parent.
  • Sticky utilities require a scrollable container.
  • All classes use logical properties, so RTL is supported automatically.
