Reset Utilities

The .reset-* classes restore native browser appearance for elements that custom styles are applied to. Compare default WispCSS styles (left) with reset styles (right) below.

Notes

  • .reset-ul — removes custom bullet dots and indentation from <ul>, restores browser default list style.
  • .reset-ol — same as .reset-ul but for <ol> (ordered lists).
  • .reset-dl — removes top/bottom borders, decorative dots, bold title style from <dl>, returns plain text definition list.
  • .reset-heading — removes margins from <h1> ~ <h6>.
