Typography / Multi-language Text

WispCSS uses a system UI font stack optimized for multi-language rendering. The following paragraphs demonstrate how each language appears with the default font settings.

Notes

  • Font stack prioritizes system UI fonts for each platform (macOS, Windows, Linux, Android, iOS).
  • Language-specific rendering is controlled via the lang attribute on the HTML element or container.
  • Chinese (lang="zh") uses text-emphasis dot underlines for <em> instead of italics. <cite> gets dashed underline, <dfn> uses bold.
  • RTL languages (Arabic, Hebrew, Persian) are supported via dir="rtl" with direction factor CSS variables.

English

Typography plays a crucial role in user interface design. A well-chosen typeface improves readability, establishes visual hierarchy, and creates a consistent brand personality across digital platforms. System UI fonts are often preferred because they provide excellent rendering performance and match the native operating system's visual style.

Simplified Chinese (简体中文)

字体在界面设计中不仅影响美观程度，更直接关系到信息的传达效率。合适的中文字体能够让长时间阅读变得更加轻松，同时在不同分辨率和不同设备上保持清晰锐利的显示效果。现代系统字体通常针对屏幕显示进行了专门优化，因此在网页和应用界面中具有更好的表现。

Traditional Chinese (繁體中文)

在數位產品設計中，字體選擇會直接影響閱讀體驗與介面質感。繁體中文字形結構較為複雜，因此需要專門優化的字體來呈現細節，才能在高解析度螢幕上維持清晰與平衡。良好的字重配置與行距控制，能讓長篇內容閱讀更加舒適。
