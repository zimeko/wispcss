Entry Component

List item container with centered text and optional side media (icons, images, checkboxes). Supports single-line truncation, multi-line expansion, states, shapes, variants, and sizes.

Notes

  • Base structure: .entry > .entry-body > .entry-label. Side slots accept any content (icons, checkboxes, text).
  • States: .entry-disabled, .entry-selected, .entry-checked.
  • Shapes: .entry-rounded, .entry-pill (pill).
  • Variants: .entry-muted (border), .entry-outline (dark border), .entry-subtle (background), .entry-ghost (hover bg).
  • Text features: .entry-nowrap (single-line truncation), .entry-multiline (wrap), .entry-padded (extra padding), .entry-hoverable (hover color).
  • Sizes: entry-4 ~ entry-15. Default is entry-9.

.entry-nowrap (single-line truncation)

This is a very long text that will be truncated with ellipsis when it exceeds the container width.

.entry-multiline (wrap)

Multi-line text that wraps automatically. Height adapts to content. Useful for longer descriptions in list items.
