Normalize / Reset

Baseline appearance of native HTML elements after WispCSS normalize is applied.

Notes

  • Normalize is applied automatically via src/normalize.css in the @layer base.
  • It resets browser inconsistencies and provides a consistent baseline across all HTML elements.
  • No additional classes are required — just use native HTML tags.
  • All elements below are shown with their normalized default appearance.
