Btns Component

Button group with shapes, sizes, widths, directions, flush mount, and grid layout.

Notes

  • Use class .btns as a container. Child elements are automatically styled as button group items.
  • Mark the active item with data-selected="true". Use [disabled] for disabled items.
  • Combining .btns-flush with direction classes (.btns-top, .btns-start, .btns-end) enables seamless edge fitting.
