Bookmark Component

Tab-switching utility with directional placement, layout structures, shape profiles, dynamic colors, and size presets. Selected item uses data-selected="true" or a nested <input type="radio" checked>.

Notes

  • Requires .bookmark base class on the container.
  • Mark selected item with data-selected="true" or nested <input type="radio" checked>.
  • Layouts: bookmark-flex, bookmark-grid, bookmark-gapped, bookmark-flush.
  • Directions: bookmark-top, bookmark-start, bookmark-end (default: bottom).
  • Shapes: bookmark-rounded, bookmark-fluid, bookmark-pill.
  • Dark variant: add bookmark-inverted for solid fill on selected item.
  • Sizes: bookmark-4 ~ bookmark-15 (bookmark-8 is default).
  • Custom color via Tailwind palette: bookmark-green-500, or raw: bookmark-[#ff0000].
  • Disabled item: add data-placeholder="true" to a child.

Custom colors

Multiple color formats are supported:

  • 1. Theme semantic colors, e.g. *-error, *-error-hover
  • 2. Tailwind built-in colors, e.g. *-indigo-500
  • 3. Raw color values, e.g. *-[#ff0000]
  • 4. CSS named colors, e.g. *-[red], *-[green]
