Aura

Conic-gradient animated border edge for containers. Requires a solid background color on the container.

Notes

  • The container must have a solid background color for the aura edge to be visible.
  • aura-* sets both border width (integer) and theme color simultaneously, e.g. aura-3 (3px + primary), aura-primary (default 1px + primary color).
  • aura-size-* controls border width only, without affecting color.
  • Color scheme utilities (aura-mono-*, aura-duotone, aura-tritone, aura-multi) build upon the base color set by aura-* or aura-mono-*.

Custom colors

Multiple color formats are supported:

  • 1. Theme semantic colors, e.g. *-error, *-error-hover
  • 2. Tailwind built-in colors, e.g. *-indigo-500
  • 3. Raw color values, e.g. *-[#ff0000]
  • 4. CSS named colors, e.g. *-[red], *-[green]
