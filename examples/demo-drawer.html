Drawer Component

Pure CSS drawer built with .drawer + .drawer-wrapper structure. Toggled by adding / removing the .drawer-open class.

Notes

  • Base: .drawer (overlay) → .drawer-wrapper (card surface).
  • .drawer-open and .drawer-close are mutually exclusive: add .drawer-open to show, remove it and add .drawer-close to hide.
  • .drawer-backdrop is optional — without it the drawer clicks through.

Available child nodes of .drawer:

  • .drawer-wrapper — content wrapper (card surface, required)
  • .drawer-backdrop — backdrop layer (optional; without it the drawer clicks through)
  • .drawer-tools — tools bar, absolutely positioned top-end (optional)
  • .drawer-header — header container (optional; auto-hidden when empty)
    • .drawer-title — title, child of header (optional, ellipsis truncation)
  • .drawer-body — scrollable main area (required)
    • .drawer-content — content container, child of body (inherits border radius)
  • .drawer-footer — bottom action area (optional)
    • .actions — action bar with start / center / end groups
    • .btns.btns-flush — flush edge-to-edge button group
  • .drawer-note — note text area at the bottom (optional)

Width

  • drawer-* — any arbitrary width.
  • drawer-scale-* — proportional sizes based on --default-width-input; drawer-scale equals the default width of <input type="text">.
  • drawer-full — full width (keeping safe side gaps).
  • Without any width utility, the drawer width depends on its content.

Tools outside

When the content fills the drawer, you may want to move the tools outside the wrapper.

.drawer-tools-outside places the tools bar outside / beside the wrapper.

Full-size media

drawer-media displays a single media item (image, video or iframe). The .drawer-body padding becomes 0 so the media fills the drawer.
