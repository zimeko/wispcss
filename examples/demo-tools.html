Tools Component

Tool button group container. Basic structure: .tools > * — each child is a tool button. Supports risk levels, disabled state, arrow indicators, plain variant, and vertical layout.

Notes

  • Base: .tools (horizontal) or .tools-v (vertical). Children can be <span>, <a>, or <button>.
  • Risk levels via data-risk: low, neutral, medium, high, extreme.
  • Disabled: data-disabled="true". Arrow: data-more="true", expanded: data-more="true" data-open="true".
  • Variant: tools-plain (no padding, text-only). Sizes: tools-4 ~ tools-15.
