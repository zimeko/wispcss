Field Component

Form field container that accommodates all form field types. Supports vertical/horizontal layout, full-width, borderless mode, dynamic sizing, and slots for label, content, control, note, and help.

Notes

  • Base structure: .field > [data-role="label"] + [data-role="content"] > [data-role="control"] + [data-role="note"] + [data-role="help"].
  • Layouts: .field (vertical), .field-h (horizontal), .field-v (vertical alias).
  • Width modes: .field-full (100%), .field-scale (1x input width), .field-scale-* (Nx input width), .field-ratio (1x input height), .field-ratio-* (Nx input height).
  • Use .field-borderless to remove input borders for embedding in custom containers. Compatible with .shell.
