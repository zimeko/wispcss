Transition Utilities

Each utility defines a single target state value. Use with Tailwind's transition-* and duration-* properties. Click the buttons below to see effects.

Notes

  • All utilities only define the target state — pair with transition-[property] and duration-* for animation.
  • Supported transitions: rotate (cross, expand, collapse, reverse), scale (up, down, in, out), 3D flip (flip-y, flip-x), translate (up, down, start, end), opacity (in, out), blur (in, out), backdrop-blur (in, out), shadow (in, out), drop-shadow (in, out).
  • Combine multiple properties: transition-[opacity,translate] duration-normal opacity-in translate-up.
