Emphasis Component

East Asian emphasis marks for <em> tags. Supports position (bottom/top), style variants (dot, double-circle, triangle, sesame), open/filled, and dynamic colors.

Notes

  • Works automatically on <em> tags for languages without italic tradition (e.g., lang="zh", lang="ja", lang="ko", lang="hi", lang="th", lang="ar").
  • Manual classes: .emphasis-bottom (force below), .emphasis-top (force above).
  • Style variants: .emphasis-dot, .emphasis-double-circle, .emphasis-triangle, .emphasis-sesame.
  • Fill: .emphasis-open for hollow outlines. Combine with style variants.
  • Color: emphasis-* dynamic utilities (e.g. emphasis-error, emphasis-green-500).

Custom colors

Multiple color formats are supported:

  • 1. Theme semantic colors, e.g. *-error, *-error-hover
  • 2. Tailwind built-in colors, e.g. *-indigo-500
  • 3. Raw color values, e.g. *-[#ff0000]
  • 4. CSS named colors, e.g. *-[red], *-[green]
