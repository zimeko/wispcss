Check Component

Modern checkbox and radio component with CSS variables and pseudo-elements.

Notes

  • Prefer combined utilities like check-subtle-primary over separate check-subtle check-primary — smaller CSS output.
  • Use check-indeterminate for semi-checked state, or the native :indeterminate pseudo-class.
  • Sizes use check-4 ~ check-15 (4 ~ 15 spacing units). Height increases by 1 spacing unit per step.
  • Shape modifiers (check-pill, check-rounded, check-square, check-fluid) apply to variants with background/border (subtle, vivid, ghost, outline, muted, tick).

Custom colors

Multiple color formats are supported:

  • 1. Theme semantic colors, e.g. *-error, *-error-hover
  • 2. Tailwind built-in colors, e.g. *-indigo-500
  • 3. Raw color values, e.g. *-[#ff0000]
  • 4. CSS named colors, e.g. *-[red], *-[green]
