Skeleton Component

Loading placeholder that renders a shimmer sweep or pulse animation. Add .skeleton to any element and set its dimensions via width / height / border-radius. All child content is automatically hidden.

Notes

  • Base: .skeleton. Requires explicit width, height, and optionally border-radius.
  • Uses a ::after pseudo-element with a diagonal shimmer gradient overlay.
  • Add .skeleton-pulse to switch from shimmer to a simple opacity breathing animation.
  • Set a background color via Tailwind utilities (e.g. bg-title-bd) or inline styles for the base skeleton color.
